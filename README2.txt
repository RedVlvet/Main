Home Page 

The Home will provide a section where users can check their previous reservation 
from either of the three services.
This page is the first page the user will see. 
This is where the user gets a general feel of what the website is about.

-Display: Info about KMK Reservations, small over view of the services we offer
-If the user is logged in display previous bookings

- MyProfile Account
This is where the user's data will be stored to include:
* email
* Password
* Phone number

KMK Reservations provides three separate services:

- Restaurant Reservations
  Where the user can tap the "explore services" button 
  that directs them to the Restaurant Reservationss webpage

  Page Color
  Background:#883DDB
  Accent:#A855F7
  Button:#6D28D9
  Text:#FFFFFF

- Display: restaurant Info(Name, Location), Reservation Date and time, Number of Adults and/or children
- Collects same as mentioned in what will be displayed


- Accomodaions
 Where the user can tap the "explore services" button 
 that directs them to the Hotel Room Reservation's webpage

 Page Color
  Background:#17BEBB
  Accent:#2DD4BF
  Button:#0EASA4
  Text:#FFFFFF

- Display: Accommodations, Check - In, Check- Out, Adults, Children and Number of rooms
- Collects same as mentioned in what will be displayed

-Driver Services 
  Where the user can tap the "explore services" button 
  that directs them to the driver Service webpage

  Page Color
  Background:#2388F5
  Accent:#60ASFA
  Button:#1D4EDB
  Text:#FFFFFF

- Display (Driver Name, Location, Journey Date, Time, Single or Return Trip, Passengers)
- Collects same as mention in what will be displayed

- My Bookings
  This is where the user can check their previous and current Reservations
  which includes the date the reservation was made and other information entered in by the user.

- When the user selects a service that they have booked/reserved,
- it shows where they can click either of the three services to look at their previous or current reservaions.
- Where when looking at the current reservation tab the user can cancel their reservation.
