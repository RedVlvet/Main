HOW TO RUN IN XAMPP
1. Install and open XAMPP Control Panel.
2. Click Start beside Apache.
3. Extract the kmk_reservations folder into C:\xampp\htdocs\
4. Confirm index.php and style.css are directly inside:
   C:\xampp\htdocs\kmk_reservations\
5. Open this address in your browser:
   http://localhost/kmk_reservations/
